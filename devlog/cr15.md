# CR-15 開發日誌 — Markdown 表格插入與編輯

**日期**: 2026-07-12
**對應需求**: change-requirements-9.md CR-15

---

## 目標

在 WYSIWYG 模式下整合 TipTap 官方表格擴充，讓使用者可透過工具列插入並調整表格結構，並確保內容正確序列化為 GFM Markdown 格式。

---

## 套件安裝

既有 TipTap 版本為 `3.22.5`，表格相關套件需固定相同版本以避免 peer dependency 衝突（最新版要求 `@tiptap/core@3.27.3`）：

```
npm install @tiptap/extension-table@3.22.5
           @tiptap/extension-table-row@3.22.5
           @tiptap/extension-table-cell@3.22.5
           @tiptap/extension-table-header@3.22.5
```

---

## 實作細節

### 1. TipTap Extensions（`EditorLayout.tsx`）

在 `useEditor` 的 extensions 陣列中加入四個表格擴充：

```ts
Table.configure({ resizable: false }),
TableRow,
TableCell,
TableHeader,
```

`resizable: false` 的理由：拖拉欄寬會產生 `colgroup` HTML，導致 `tiptap-markdown` 序列化時在 Markdown 中產生額外的 HTML 標籤，破壞 GFM 格式整潔性。

由於專案已使用 `tiptap-markdown`（`editor.storage.markdown.getMarkdown()`），表格自動序列化為標準 GFM 格式：

```markdown
| 欄位一 | 欄位二 | 欄位三 |
| ------ | ------ | ------ |
| 資料   | 資料   | 資料   |
```

無需額外設定。

---

### 2. TableDialog 元件（新增）

新增 `web/src/app/components/TableDialog/` 目錄：

- **`TableDialog.tsx`**：讓使用者在插入前設定欄數（1–10）、列數（1–20）、是否包含標題列。
- **`TableDialog.module.css`**：樣式與現有 Dialog 系列一致（overlay + slideUp 動畫）。

#### Props

```ts
interface TableDialogProps {
  open: boolean;
  onClose: () => void;
  onInsert: (rows: number, cols: number, withHeaderRow: boolean) => void;
}
```

#### 輸入驗證

- 欄數或列數超出範圍時，「插入」按鈕設為 `disabled`。
- 輸入框邊框變紅（`.inputError`）提示錯誤範圍。
- Enter 鍵觸發插入、Escape 鍵關閉 Dialog。

---

### 3. EditorLayout.tsx 整合

新增 state 與 handler：

```ts
const [tableDialogOpen, setTableDialogOpen] = useState(false);

const handleTableInsert = useCallback(
  (rows: number, cols: number, withHeaderRow: boolean) => {
    editor?.chain().focus().insertTable({ rows, cols, withHeaderRow }).run();
    setTableDialogOpen(false);
  },
  [editor],
);
```

JSX 掛載：

```tsx
<TableDialog
  open={tableDialogOpen}
  onClose={() => setTableDialogOpen(false)}
  onInsert={handleTableInsert}
/>
```

`Toolbar` 新增 `onTable={() => setTableDialogOpen(true)}` prop。

---

### 4. Toolbar 變更（`Toolbar.tsx`）

#### 新增 `onTable` prop

```ts
interface ToolbarProps {
  // ...
  onTable: () => void;
}
```

#### 插入表格按鈕

在「水平分隔線」群組之後新增一個獨立群組，按鈕以 `⊞` 字元標示：

```tsx
<button
  className={`${styles.btn} ${isActive('table') ? styles.active : ''}`}
  onClick={onTable}
  aria-label="插入表格"
  title="插入表格"
>
  ⊞
</button>
```

游標在表格內時（`isActive('table') === true`），按鈕呈現 active 藍底，提示當前所在位置。

#### 表格內上下文操作列

以條件渲染（`{isActive('table') && ...}`）在「⊞」群組之後展開操作按鈕，游標離開表格後自動收起：

| 按鈕 | TipTap 指令 | 說明 |
| ---- | ----------- | ---- |
| `+列↓` | `addRowAfter()` | 在當前列下方插入一列 |
| `−列`  | `deleteRow()` | 刪除當前列 |
| `+欄→` | `addColumnAfter()` | 在當前欄右側插入一欄 |
| `−欄`  | `deleteColumn()` | 刪除當前欄 |
| `刪除表格` | `deleteTable()` | 刪除整個表格（紅色警示樣式） |

所有按鈕使用 `onMouseDown={cmd(...)}` 以保持游標焦點不跳離編輯器。

## 設計決策

| 決策 | 說明 |
| ---- | ---- |
| `resizable: false` | 防止欄寬拖拉產生 HTML colgroup，保持 Markdown 輸出整潔 |
| 上下文操作列以條件渲染展開，而非獨立元件 | 維持工具列為單一平面結構，減少 DOM 層級；游標位置即隱即現，操作流暢 |
| `onTable` 使用 `onClick` 而非 `onMouseDown` | 插入表格不需要保留編輯器焦點（Dialog 會取得焦點），符合現有 onRuby / onImage 慣例 |
| `withHeaderRow` 由 Dialog 控制，透過 `onInsert` 簽章傳入 | 相較於 spec 原本的硬編碼 `true`，讓使用者選擇更靈活；簽章調整為 `(rows, cols, withHeaderRow)` |
| 版本固定 `3.22.5` | 避免 peer dep 衝突；未來統一升級 TipTap 時一併處理 |
