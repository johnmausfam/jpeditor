# CR-16 開發日誌 — 振假名分隔字元擴充

**日期**: 2026-08-01
**對應需求**: change-requirements-10.md CR-16

---

## 目標

擴充 `rubyExtension.ts` 的 Markdown 解析規則，使振假名語法除原有的 `|` 外，同時接受 `;` 與 `/` 作為文字與讀音之間的分隔字元，序列化輸出維持 `|` 格式不變。

---

## 修改內容

### 修改檔案

`web/src/app/lib/rubyExtension.ts`（僅此一處）

### 修改位置

`addStorage().markdown.parse.setup()` 中的 `rubyRule` inline 規則函式。

---

## 實作細節

### 修改前

```ts
let pipePos = -1;
let end = -1;

for (let i = pos + 1; i <= max; i++) {
  const ch = state.src.charCodeAt(i);
  if (ch === 0x0a) return false;
  if (ch === 0x7c && pipePos === -1) pipePos = i; // '|'
  if (ch === 0x7d) { end = i; break; }
}

if (pipePos === -1 || end === -1) return false;
if (pipePos <= pos + 1 || end <= pipePos + 1) return false;

token.attrSet('data-text',    state.src.slice(pos + 1, pipePos));
token.attrSet('data-reading', state.src.slice(pipePos + 1, end));
token.content = state.src.slice(pos + 1, pipePos);
```

### 修改後

```ts
let sepPos = -1;
let end = -1;

for (let i = pos + 1; i <= max; i++) {
  const ch = state.src.charCodeAt(i);
  if (ch === 0x0a) return false;
  // 0x7c = '|'  0x3b = ';'  0x2f = '/'
  if ((ch === 0x7c || ch === 0x3b || ch === 0x2f) && sepPos === -1) {
    sepPos = i; // 第一個分隔符
  }
  if (ch === 0x7d) { end = i; break; }
}

if (sepPos === -1 || end === -1) return false;
if (sepPos <= pos + 1 || end <= sepPos + 1) return false;

token.attrSet('data-text',    state.src.slice(pos + 1, sepPos));
token.attrSet('data-reading', state.src.slice(sepPos + 1, end));
token.content = state.src.slice(pos + 1, sepPos);
```

### 變更要點

- 變數 `pipePos` 重新命名為 `sepPos`，語義從「pipe 的位置」擴展為「任一分隔符的位置」。
- 分隔符偵測條件新增 `0x3b`（`;`）與 `0x2f`（`/`），與原本的 `0x7c`（`|`）並列。
- 迴圈邏輯維持「取最先出現者」，後續出現的同類字元視為讀音內容的一部分。
- `serialize()` 輸出 `{text|reading}` 的行為完全不變，無修改。

---

## 設計決策

| 決策 | 說明 |
| ---- | ---- |
| 序列化輸出維持 `\|` | 確保既有文件儲存格式相容，也讓輸出格式唯一、可預測 |
| 取「最先出現的分隔符」 | 行為與原 `\|` 邏輯一致，實作最簡單且無歧義 |
| 無需修改其他檔案 | 解析邏輯完全封裝於 `rubyExtension.ts` 的 `setup()` 內，對外介面（TipTap node attrs、commands、serializer）不變 |
